# REGION Overlay

Окно поверх игры: поиск по правилам, быстрые ответы, биндер. Открывается и скрывается горячей клавишей (по умолчанию **Alt+R**).

## Запуск
1. Установите Node.js 20+ → дважды щёлкните `start.bat` (или `npm install && npm start`).
2. Подключение одним ключом: на сайте откройте профиль, раздел «Оверлей для игры», нажмите «Создать ключ» и откройте оверлей: он сам найдёт ключ в буфере обмена (или вставьте его в «Настройки»). Адрес сайта зашит в ключ, вводить его не нужно. Данные подгрузятся и сохранятся на диск, дальше работает и без сети.

Готовый установщик/portable `.exe`: `npm run dist` на Windows (результат в `dist/`) или workflow «Сборка для Windows» в GitHub Actions.

## Сервер (RegionWiki)
На сайте работают `src/app/api/overlay/data/route.ts` (правила и быстрые ответы), `.../punishments/*` (наказания), `.../me` (проверка ключа). Правила отдаются открыто (как на сайте), всё остальное только по личному ключу и в рамках прав его владельца.
Если сайт стоит за прокси и адрес в ключе получается неверным, задайте на сервере `OVERLAY_SITE_URL` (например `https://wiki.example.ru`). Общий `OVERLAY_TOKEN` остаётся только для старых версий оверлея.

## Как пользоваться
- **Всё.** Общий поиск по правилам, быстрым ответам и биндам сразу (вкладка открывается первой). Enter — действие над выбранным (правило: копировать номер, ответ: копировать, бинд: отправить в игру), Shift+Enter — правило с текстом.
- **Правила.** «ОП 1.19» или «1.19» — по номеру; «ограбить», «баг» — по словам (учитываются окончания). Фильтр по разделам, ↑/↓ — выбор, Enter — копировать «ОП 1.19», Shift+Enter — с текстом, клик по карточке копирует «ОП 1.19», кнопка ▾ разворачивает наказание, примечания и исключения.
- **Ответы.** Клик по блоку ответа (или Enter) копирует текст ответа. Можно включить «Вставлять сразу» — после копирования окно скроется и в игру вставится Ctrl+V.
- **Биндер.** «+ Бинд»: название, сочетание клавиш, текст (строка = сообщение). Бинд срабатывает по горячей клавише прямо в игре: для каждой строки нажимается клавиша чата (если задана), вставляется текст и жмётся Enter. Клавиша чата и пауза задаются глобально в настройках или на каждый бинд.
- **Подсказки на экране игры.** Маленькая прозрачная панель со списком биндов («Ctrl+Alt+1 — Приветствие ×2») висит поверх игры и не перехватывает мышь. Включается в «Настройках» или клавишей **Alt+H**; там же угол экрана, размер и прозрачность. Строка вспыхивает, когда бинд срабатывает. Бинд можно исключить из панели галочкой в его настройках.
- **Свёрнутый режим.** Кнопка ⤡ в шапке (или Ctrl+M) сворачивает оверлей в одну строку поиска: логотип, поле, переключатель «Всё / Правила / Ответы», история запросов и кнопка ⤢ для возврата. Когда вы вводите запрос, строка выпадает вниз списком результатов, а когда очищаете, снова сжимается. Положение и режим запоминаются, Alt+R открывает оверлей в том режиме, в котором вы его оставили.
- Esc — скрыть (или очистить поиск). Ctrl+1…5 — вкладки. Окно двигается за шапку, размер и позиция запоминаются.

## Важно
- Игра должна идти в режиме **«в окне» или «окно без рамок»**: поверх настоящего полноэкранного режима окна не рисуются.
- Вставка и биндер работают на Windows (PowerShell + SendKeys). Если игра запущена от администратора, запускайте оверлей тоже от администратора, иначе Windows не даст ему нажимать клавиши.
- Не ставьте на бинд сочетание, которое уже использует игра: глобальная клавиша перехватывается оверлеем. Занятые сочетания подсвечиваются красным.
- Чат-команды вроде `/mute …` в биндах отправляются как обычные строки; убедитесь, что античит сервера допускает автоматический ввод.

## Сборка .exe

Запустите **build.bat** двойным кликом: он поставит зависимости, прогонит тесты и соберёт приложение в папку `dist`
(portable `.exe` и установщик). `build.bat portable` собирает только один файл без установки, `build.bat installer` только установщик.
Нужен Node.js LTS. Запуск без сборки: **start.bat**.
